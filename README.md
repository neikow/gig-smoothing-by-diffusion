# Smoothing by diffusion algorithms

## How to build

The C++ project uses FetchContent so the required dependencies will be
automatically downloaded during the build process.

To build the project, create a build directory and run CMake:

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## How to run

After changing the parameters in `main.cpp:main()` you can run the build and run the executable: it will generate the
output files in the `output/` folder.
